## Executive summary

**2026-27 results are published, and the earlier survey was wrong to say they are not.**

The survey (§5b) read the MaxPreps *team landing* page, saw `Team Leaders — Athlete Stats have not been entered`, and concluded there were no 2026-27 times anywhere. There are **41 attributed individual swims and 9 relay swims** from one meet.

Every one of those rows carries a **date and a meet name**, which is what `records/*.md` requires, so this is not the unattributed-leaderboard shape the work order warned about.

**One record moved.** Boys 500 Freestyle: Kent Olsson, 5:03.13, breaking both the Sophomore class record (5:19.88) and the **Open school record of 5:04.10 that had stood since 2015**. That is the only change to any existing record value in this PR, it is corroborated by two independent sources, and §5 proves nothing else moved.

**This is a mid-flight season: one meet.** Every page produced says so on its face.

## 2. Verifying the harvesters before trusting their 2026-27 output

### `harvest_all_relay_splits.py` — reproduces **all 14** committed seasons byte-identically

The work order said this script "already covers 26-27". **It did not** — its `YEARS` list ended at `'25-26'`. Added `'26-27'` (one line).

Run from a scratch directory (never against the repo tree), then compared against what is committed:

```
IDENTICAL  splits_13-14.json    IDENTICAL  splits_20-21.json

IDENTICAL  splits_18-19.json    IDENTICAL  splits_25-26.json
identical=14 differs=0
```

The importer assessment checked six season/gender pairs; this checks **all fourteen seasons**, and they all reproduce exactly. The harvester is trustworthy, so its 26-27 output is too.

### A trap avoided in the combined splits file

`splits_YY-YY.json` reproduce exactly, but `all_relay_splits.json` did **not** — and the difference is **pure ordering**. The committed combined file runs oldest→newest (`12-13 … 25-26`); a fresh run with `YEARS` newest-first emits `25-26 … 12-13`. Content per season is identical.

Blindly committing the fresh file would have produced a 454-entry reordering diff that looks like mass data change but isn't — and worse, `generate_website.py:757` and `rebuild_relay_pages.py:86` attach splits to a record row by taking the **first** entry matching event-type plus ≥3 swimmer-name overlap. Reordering that list can silently change which splits attach to which historical relay row.

So the combined files here are the **committed content, untouched, with the nine 26-27 entries appended**. `git diff` confirms **504 insertions, 0 deletions** across the three combined files.

## 4. What was deliberately excluded

**Everything below was found and is left out on purpose.**

### 4a. Relay times — excluded from `relay-records-*.md`

Nine relay swims were harvested with date and meet. None of them break a record, but three would enter the top-10 lists on time alone (e.g. boys 200 Medley 1:45.93 would slot ~7th against a list whose rank 7 is 1:46.38).

They are excluded because **MaxPreps names the entrant `Relay Team`, not the four swimmers**, and `relay-records-*.md` has a `Participants` column. The split windows do carry four names, but joining a split set to a relay time is exactly the weak, lossy join the survey flagged as R3 — event-type string equality plus name overlap, with no total-vs-sum reconciliation. Manufacturing a participant list through that join is inference, not a read, so it was not done.

Inserting rows would also renumber ranks in a file that **already fails the linter** (the pre-existing R4 duplicate, §6). That is PR #1's territory, not this PR's.

### 4b. azpreps365 — available but unattributed, used only to cross-check

43 Tanque Verde rows, and they are genuinely useful — they **independently confirmed the 500 Free record** (§5). But the individual rows carry no date and no meet name, so none were written into `records/`.

Two further findings about this source, both corrections to earlier claims:

- **The relay rows are structurally broken in the harvester's output.** The `time` column contains `Canyon del Oro Classic` and the athlete column is empty — a column-shift on relay pages, where there is no athlete cell. So azpreps365 relay rows carry a *meet name* but have **lost the time**. The survey called this source "division leaderboards with no dates or meet names"; for relays it is closer to the opposite. Either way it is unusable as written.
- **azpreps365 mixes relay lead-off splits into individual event standings.** Several rows have no counterpart in MaxPreps' individual tables and reconcile exactly against the split data:

  | azpreps365 row | reconciles as |
  |---|---|
  | boys 100 Free, Jackson Machamer 54.24 | 25.79 + 28.45, 400 FR legs 1-2 |
  | girls 100 Free, Rachel Anderson 59.24 | 28.74 + 30.50, 400 FR legs 1-2 |
  | girls 100 Free, Ella Bissmeyer 1:02.21 | 30.05 + 32.16, 400 FR legs 1-2 |
  | girls 50 Free, Stella Eftekhar 26.70 | 200 FR lead-off (MaxPreps flat start: 27.00) |
  | boys 50 Free, Bennett Johnston 24.79 | 200 FR lead-off |

  This is **survey OPEN QUESTION 1 made concrete**. Sourcing records from MaxPreps' individual tables sidesteps it entirely: nothing lead-off-derived entered `records/`. If Aaryn's rule is that lead-offs *do* count, these five swims are candidates and this PR has not applied them.

### 4c. Two visible data-quality defects in the 2026-27 relay splits

Harvested as-is into `splits_26-27.json` (that file is a faithful record of what the source says) but flagged rather than trusted:

- **Girls 200 Medley Relay** legs `31.28 / 35.76 / 36.59 / 21.44`. The 21.44 free leg is implausible next to a 36.59 fly and would beat the girls 50 Free *Open* record of 23.84. It is an anchor leg off a rolling start. The legs sum to 2:05.07, matching the recorded total, so the total is right and the split distribution is suspect.
- **Girls 400 Free Relay** legs include `15.29` then `43.22` for Hadley Cusson. The pair sums to 58.51 and the eight legs sum to 4:02.36, matching the total — so it is a mis-placed 50 boundary inside a correct 100.

Neither affects any record, because no lead-off or split was promoted to an individual time.

3. **It is continuous with his own history, not an outlier.** Kent Olsson holds the *Freshman* 500 Free record at 5:07.85 (Nov 8, 2025). A sophomore-year drop of 4.7s is an ordinary year of improvement — this is not a stray time attached to the wrong swimmer.

## 10. Open questions for Aaryn

1. **Sign off on the 500 Freestyle record.** This is the one thing in this PR that changes history. Kent Olsson 5:03.13 replaces Joseph Breinholt's 5:04.10 from Oct 24, 2015. It is corroborated by two independent sources, but **it is a regular-season invitational result reported to MaxPreps, not an AIA-certified one**, and this repo has **no way to express "provisional"** (survey §6 — no provisional flag, no DQ flag, no source-confidence field anywhere). The file says so in a visible note, but the metric will quietly drift if someone just re-runs later in the season.
